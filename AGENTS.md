# AGENTS

## Release

Nothing in this repo is released by tag (Tupic's [Release Guideline](https://tupic.atlassian.net/wiki/spaces/TPRD/pages/1245412)):

- Trunk-based: branch from `main` and merge back by pull request. `main` is the only long-lived branch: no `dev`,
  `develop` or `release/*` branches.
- A merge to `main` publishes the site (GitHub Pages).
